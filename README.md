# tyrajmisiu certyfikat

Certyfikat robienia tiramisu firmy Tyraj Misiu, zatwierdzany przez Wiksasa.

Wpisujesz imię, wybierasz stopień, zaznaczasz kroki przepisu i dajesz Wiksasowi do zatwierdzenia. Po zatwierdzeniu certyfikat dostaje datę, numer, podpis i pieczątkę, a przycisk drukowania drukuje sam certyfikat (albo zapisuje go jako PDF).

Statyczna strona bez builda: `index.html`, `styles.css`, `app.js`, grafiki w `assets/`. Czcionki (Titan One, Nunito, Caveat) leżą w `assets/fonts/` jako woff2 przycięte do łaciny z polskimi literami, bez zależności od Google Fonts. Lokalnie:

```sh
python -m http.server 8765
```
